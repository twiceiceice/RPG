# 바람의 들판

야외 보스 폭풍뿔 바르칸과 거울 마녀 리세아를 공략하고, 사냥·벌목·거래·건축·전사 성장을 즐기는 싱글 플레이 3D 액션 RPG입니다. 마인크래프트식 마을 습격에서 위치 선정과 패턴 대응 중심의 보스 의뢰로 전환했습니다. LLM 연결은 없습니다.

## 실행

집이나 다른 컴퓨터에서 이어서 작업하려면 [HANDOFF.md](./HANDOFF.md)의 내려받기·실행 방법과 현재 개발 상태를 먼저 확인하세요.

Node.js가 있는 환경에서 이 폴더를 열고 `npm ci` → `npm run build` → `npm start`를 실행한 뒤 http://127.0.0.1:4173 에 접속하세요. 이미 빌드된 다운로드 소스는 `node serve.mjs`만 실행해도 됩니다.

게임 소스는 `dist/*.js`, 화면 원본은 `index.template.html`입니다. 게임이나 화면 원본을 수정하면 `npm run build`로 `dist/index.html`을 다시 만드세요. `dist/index.html`은 생성 파일입니다. 스타일은 `dist/style.css`에서 수정합니다.

외부 Firefox에서 여러 JavaScript 모듈의 로드가 실패해 로딩 화면에 머무는 문제에 대응해, Three.js와 게임 소스를 한 번들로 묶어 HTML에 포함합니다. 실행 시 개별 전투·마을 모듈을 추가로 요청하지 않으며, 브라우저 캐시에 서로 다른 버전의 모듈이 섞일 여지도 줄입니다. 초기화 오류가 나면 오류 내용과 다시 불러오기 버튼을 보여 줍니다. 브라우저의 보안 설정이나 저장된 게임 진행은 변경하지 않습니다.

## 조작

### 마을 확장 · 건축 · 성장 · 소리

- 마을은 30×26m에서 54×44m로 약 3.05배 넓어졌습니다. 기존 서쪽 전투 출입구를 유지하고 상점과 통로를 벌렸습니다. 햇살 터·바람 터(각 12×12m), 솔향 터(12×10m)는 평탄한 개인 건축 공간입니다.
- **K 건축:** 부지 선택 → 부지로 이동 → 1 나무 / 2 돌 / 3 지붕 → 중앙 조준점의 초록 미리보기에 좌클릭 설치, 우클릭 회수. Q/E 또는 우클릭 드래그로 시점 변경. 설치·회수 버튼도 제공하며, 최대 7m 사거리·8층·600블록입니다. 자재는 호두에게 구매·교환하고, 회수하면 같은 블록 한 개가 돌아옵니다. 주민·캐릭터·기존 건물과 겹치거나 부지 밖에는 설치되지 않습니다. 전투 중에는 건축할 수 없습니다. 제작은 후속 기능입니다.
- 주민은 총 10명입니다. 두 보스 토벌 모두 나리를 선택해서 동행시킬 수 있습니다.
- **P 특성:** 최고 10레벨, 1레벨에 1점과 이후 레벨마다 1점으로 총 10점. 힘찬 일격 / 든든한 전사 / 바람의 춤의 12개 특성에서 선택합니다. 위 특성 1점과 3·5·8레벨 조건으로 아래 줄을 엽니다. 첫 두 줄은 각 2등급, 나머지는 1등급이며 갈래 혼합이 가능합니다. 전투 중 습득은 금지하고, 평화로운 마을에서 무료 초기화합니다.
- 경험치: 토끼 12, 슬라임 24, 나무 18, 보스 각각 150, 첫 토벌 의뢰 보고 각각 180. 리세아의 분신·거래·블록 설치 반복에는 XP가 없습니다. 다음 레벨까지 60/100/150/210/280/360/450/550/660 XP가 필요합니다. 레벨마다 최대 체력 +4, 레벨 상승 시 생존한 플레이어의 체력을 회복합니다.
- 특성은 공격 피해, 내려찍기, 체력 30% 이하 대상 추가 피해, 치명타 2.3배, 최대 체력, 피해 감소, 처치 회복, 연계 시간, 회전 피해·범위·지속 시간을 실제 판정에 반영합니다. 기본 근접 공격 간격은 여전히 2초입니다. 최종 회전 특성은 기본 3초, 최대 5초까지 연장합니다.
- **♫ 소리:** 직접 만든 가벼운 반복 음악과 무기·기술별 효과음을 Web Audio로 합성합니다. 첫 클릭이나 키 입력 후 시작하며 음악과 효과음 음량을 따로 조절하고 모두 끌 수 있습니다. 일시정지와 숨긴 탭에서는 음소거합니다. 외부 음악 파일 요청은 없습니다. 선호 음량은 이 브라우저에 저장합니다.
- 기존 `windfield-village-v1` 저장에 경험치·특성과 건축 좌표를 함께 추가합니다. 이전 저장의 골드·자재·강화·승리 기록을 보존하고 건축물 충돌도 복원합니다. 다른 브라우저와는 공유되지 않습니다.
- 검사: `node tests/expansion.mjs`로 저장 호환성, 10레벨·포인트 제한, 특성 실효과, 사망 회복 경계, 건축 재고·충돌, 실제 부지 지형과 주민 배치, 전투 보상, 소리 제어를 검증합니다.

- WASD 또는 방향키: 카메라 방향을 기준으로 이동
- 마우스: 시작 버튼 후 자유 시점, 또는 우클릭 드래그로 회전. 마우스 잠금이 지원되지 않는 브라우저에서도 드래그로 조작할 수 있습니다.
- Q / E: 키보드 시점 회전. 가까운 주민이 있으면 E는 대화로 사용합니다.
- B: 솔바람 마을 광장으로 이동. 시작 화면의 ‘마을에서 시작’이나 상단 마을 버튼도 같습니다.
- J: 토벌 의뢰. 바르칸 또는 리세아 선택 → 마을에서 의뢰 수락 → 해당 전장으로 이동 → J에서 도전. 메뉴를 열면 시간이 멈춥니다.
- G: 나리 동행 중 집결 지시. 오른쪽 동행 버튼도 같습니다.
- E: 2.9m 안의 주민과 대화·거래. 화면의 대화 버튼을 눌러도 됩니다. Esc 또는 ×로 대화를 마칩니다.
- H: 회복 물약 1개로 체력 45 회복, 재사용 4초. 체력이 가득하거나 쓰러졌을 때는 소모하지 않습니다.
- Shift: 달리기
- Space: 점프
- 1: 돌진. 전방으로 빠르게 이동하며 부딪힌 적을 밀어냅니다. 벽이나 바위를 통과하지 않습니다.
- 2: 내려찍기. 날을 세로로 세운 뒤 빠르게 내려찍어 날끝을 땅에 꽂습니다.
- 3: 날아차기. 박힌 도끼를 짚고 실제로 약 3.2m 전진하며 점프합니다. 도약 후 손을 놓고 발을 뻗어 적을 밀칩니다.
- 4: 가로베기. 현재 위치에서 뒤에 남은 도끼를 끌어와 잡고, 앞으로 파고들며 크게 가로로 벱니다. 도끼를 가지러 뒤로 이동하지 않습니다.
- 5: 궁극기 회전베기. 1 → 2 → 3 → 4 적중으로 준비한 뒤 원하는 때 사용합니다. 회전 중 WASD로 이동할 수 있습니다.
- Z / X / C: 양손 도끼 / 칼 / 활 장착. 게임은 도끼를 든 전사로 시작합니다.
- 활은 좌클릭을 누르고 활시위를 당긴 뒤 놓으면 한 발 발사합니다. 약 1.05초면 가득 당겨지며, 짧게 눌러도 발사됩니다. 화살은 무제한입니다.
- 활을 당기는 동안 마우스로 계속 조준할 수 있습니다. 시위와 화살, 손이 함께 움직이고 중앙의 막대가 당긴 정도를 표시합니다. 무기 변경, 일시정지, 창 전환, R은 발사 없이 당기기를 취소합니다.
- 도끼와 칼은 근접 사거리에 살아 있는 적이 들어오면 자동 공격합니다. 좌클릭으로 직접 기본 공격할 수도 있습니다. 잠금 없는 화면에서 근접 무기를 든 채 좌클릭 드래그하면 시점을 회전합니다.
- V: 1인칭 / 3인칭
- 마우스 휠: 카메라 거리, 가까이 당기면 1인칭
- R: 시작 위치로 돌아가 체력 회복. 쓰러진 뒤에도 사용 가능합니다.
- Esc: 일시정지 / 마우스 해제
- 터치: 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 시점, 아래 기술 버튼 1~5, 무기 선택 및 공격·점프·달리기 버튼. 활의 당기기 버튼도 누르고 있다 놓으면 발사합니다.

## 솔바람 마을과 거래

마을은 안전 지역입니다. 전투 중에는 거래와 B 이동이 잠기고, J 메뉴의 철수 또는 R로 전투를 끝낼 수 있습니다.

## 폭풍뿔 바르칸 · 야외 토벌

**B 마을 → J 의뢰 받기 → 분지로 이동 → J 바르칸 깨우기.** 마을 서쪽 천둥잠 분지에 평상시에도 보이는 돌갑옷 야수가 있습니다. 잡몹 파동 없이 보스 한 마리와 바로 싸웁니다. 단독 또는 나리 한 명 동행을 고릅니다. 나리는 체력 55% 이하일 때 최대 24씩, 14초 간격으로 총 세 번 치유합니다. 동행자가 쓰러져도 토벌은 계속됩니다.

| 패턴 | 대응 | 기본 피해 |
| --- | --- | --- |
| 뿔 휩쓸기 | 2.2초 예고 후 앞쪽 부채꼴 공격. 옆·뒤로 이동 | 16 |
| 번개 낙인 | 2.5초 추적 후 1.5초 고정. 원을 가장자리에 놓고 벗어나기 | 16, 잔류 바닥 초당 4 |
| 울림의 파동 | 2.2초에 안쪽 폭발, 3.9초에 바깥 고리 폭발. 먼저 바깥, 다음 안쪽 | 18 |
| 공명석 과부하 | 4.8초 동안 따라오는 번개를 빛나는 공명석에 유도. 1.5초 뒤 낙뢰 | 16, 성공 시 흡수 |

공명석 중심 2.1m 안에 번개 원의 중심을 고정하면 돌이 깨지고, 바르칸이 8초간 쓰러져 받는 피해가 40% 늘어납니다. 이때 6 함성, 도끼 연계와 준비한 5 회전베기를 사용합니다. 실패하면 잔류 번개가 생기지만 다음 공명석 기회가 다시 돌아옵니다. 발차기로 이 기믹을 건너뛸 수 없습니다.

보스 체력은 2400으로 고정. 체력 65%·35%에서 공명석 패턴을 다시 제시하고, 3단계는 파동에 낙인을 겹칩니다. 토벌 중 자동 체력 회복은 멈추며 물약·나리 치유는 유효합니다. 바닥 피해는 대상마다 0.9초의 공통 간격을 두고 F 회피 무적도 적용합니다. 마을 깃발·증원·승리 횟수에 따른 자동 난도 상승·전투 제한 시간은 없습니다. 분지 중심에서 25m 이상 이탈하거나 쓰러지면 종료되고 J에서 재도전할 수 있습니다.

처치마다 150 XP. 첫 의뢰는 마을에서 보고하면 80 골드·나무 12·돌 8·지붕 4·180 XP를 한 번 받습니다. 두 번째 토벌부터 12 골드·돌 2개를 즉시 받습니다. 의뢰 상태·처치 횟수·최단 시간·보상 수령 여부를 기존 세이브에 추가하며, 전투 중간은 저장하지 않습니다. **현재 주간 제한은 없으며** 주간 변형·장비 보상은 후속 기능입니다.

구형 습격 코드는 향후 세력 원정을 위한 기반으로 남아 있지만 현재 게임 메뉴에서는 실행하지 않습니다. `raids.js`의 경로 탐색·NPC 지원과 `raid-boss.js`의 공통 범위 판정·회피를 재사용합니다. 실제 야외 전투는 `field-hunt.js`, `field-boss.js`, `field-view.js`, `field-data.js`가 담당합니다.

## 거울 마녀 리세아 · 두 번째 야외 토벌

**B 마을 → J 리세아 선택 → 의뢰 받기 → 월영 회랑으로 이동 → J 리세아에게 도전.** 바르칸 처치 여부와 무관하게 바로 선택할 수 있습니다. 북서쪽 회랑에서 가면과 긴 로브를 두른 술사가 공중에 떠서 싸웁니다. 세 검은 기둥은 실제로 이동·공격·시선을 막습니다.

| 패턴 | 대응 | 기본 피해 |
| --- | --- | --- |
| 접히는 장막 | 세 직선 띠가 2.1 / 2.7 / 3.3초에 순서대로 폭발. 띠 사이 빈 통로로 이동 | 14 |
| 만월의 응시 | 4.5초 후 전장 섬광. 리세아와 자신 사이에 기둥을 두기. 청록색 바닥은 엄폐 위치 안내 | 18, 엄폐 성공 시 0 |
| 시계바늘 왈츠 | 2.4초 예고 후 얇은 광선이 4.8초간 회전. 화살표 방향으로 함께 이동 | 10, 공통 0.9초 피해 간격 |
| 거울무도회 | 16초 동안 세 분신 중 **검은 그림자가 있는 진짜** 공격. 점선 원은 가짜 | 가짜를 깨면 1.6초 뒤 파편 12 |

무도회 동안 본체는 사라지고 공격 대상에서 빠집니다. 진짜를 맞히면 모든 분신과 파편이 사라지고 본체가 **7초간 노출되어 받는 피해 +40%**. 분신은 경험치·처치 보상·처치 회복을 주지 않으며 나리가 대신 해결하지 않습니다. 놓쳐도 즉사하지 않습니다. 분신이 사라진 뒤 3.5초 예고를 주는 응시를 엄폐하고 다음 기회에 다시 도전합니다.

체력 2200, 65%·35%에서 무도회를 다시 제시하고 마지막 단계는 반대편 광선 한 줄을 더합니다. 전장 중심에서 24m를 벗어나면 종료됩니다. 단독 또는 나리 동행을 고를 수 있으며 나리는 응시 때 실제 기둥 뒤로 이동합니다. 자동 회복 중단, 물약, 공통 피격 간격은 바르칸과 같습니다.

처치마다 150 XP. 첫 보고는 **90 골드·나무 6·돌 12·지붕 6·180 XP**, 두 번째부터 **14 골드·돌 2개**입니다. 바르칸과 리세아의 의뢰·첫 보상·처치 횟수·최단 시간은 각각 저장합니다. 기존 세이브는 그대로 사용하며 리세아 항목만 추가합니다. 주간 잠금은 없습니다.

## 마을 상점

시작 지점 동쪽 길을 따라가면 집 다섯 채, 우물과 광장, 노점, 대장간과 여관이 있는 솔바람 마을을 만납니다. 미라·나리·도윤·보리·호두는 가게 앞에서 손님을 맞고, 준과 하리는 마을을 돌아다닙니다. 가까이 다가가면 주민이 플레이어를 바라보고 E 대화 버튼이 나타납니다. 벽 너머나 멀리서는 거래할 수 없습니다.

| 주민 | 거래 |
| --- | --- |
| 목재 상인 미라 | 목재 1개 판매 +2 골드, 5개 판매 +10 골드, 구매 4 골드 |
| 약초상 나리 | 회복 물약 1개 12 골드. H로 사용하면 체력 +45 |

호두의 상점은 구매·판매·물물교환 탭으로 나뉩니다. 건축 블록은 기존 목재와 별도 인벤토리로 보관·자동 저장됩니다. 사냥으로 번 골드만으로도 세 자재를 구매할 수 있습니다. 블록 설치·회수와 야외 토벌도 가능합니다. 제작과 LLM 대화는 후속 단계입니다. 이전 저장 데이터에 블록 수량이 없어도 기존 골드와 강화는 그대로 복원됩니다.

첫 실행에 20 골드와 물약 1개를 받습니다. 토끼를 처치하면 3 골드, 슬라임은 5 골드가 자동 지급됩니다. 목재·물약·골드가 부족한 거래는 실행되지 않으며, 클릭할 때마다 거리와 가격을 다시 검사합니다. 갑옷은 공격 피해에 영향을 주지 않습니다.

마을은 안전 지역입니다. 자동·수동 공격과 기술은 쉬고, 적은 경계 밖에 머뭅니다. 마을로 들어오는 진행 중 공격도 중단하지만 이미 충전된 궁극기는 보관합니다. 대화 중에는 시뮬레이션이 멈추며 창을 닫으면 이어집니다. B 이동은 살아 있고 동작·활 당기기·박힌 도끼가 없으며, 마지막 피격 후 6초가 지나고 살아 있는 슬라임이 8m 안에 없을 때 가능합니다. 이동으로 체력이나 기술 쿨타임은 초기화되지 않습니다.

골드·물약·갑옷·목재·벌목 손잡이 강화·건축 블록은 `localStorage`의 `windfield-village-v1`에 자동 저장됩니다. 새로고침·사망·R 후에도 유지되며 브라우저와 사이트 주소마다 별도입니다. 위치·적 상태·체력·연계·처치 수는 저장하지 않습니다. 저장 차단 시 오류 없이 현재 플레이 동안 유지하며 대화창에 안내합니다. 사이트 데이터를 지우면 새 게임으로 시작합니다.

## 전사 연계

각 기술은 개별 단축키와 재사용 대기시간이 있습니다. 돌진 → 내려찍기 → 날아차기 → 가로베기 순서로 연계할 수 있고, 내려찍기부터 시작하거나 날아차기를 생략하고 가로베기로 마무리해도 됩니다. 네 동작은 합계 3.2초(타격 정지 제외)입니다. 공격·회피·짧은 경직 도중 다음 기술을 한 번 미리 누르면 사용 가능한 순간에 이어집니다. 착지 직전 예약은 최대 0.45초 기다립니다. 도끼가 박힌 뒤 약 3초 안에 3번이나 4번을 누르세요. 움직이거나 점프하거나 무기를 바꾸면 도끼를 회수하며, 이때 공격 피해는 발생하지 않습니다. 시간이 지나도 자동 회수됩니다.

3번 날아차기와 4번 가로베기는 각각 **발동하는 순간의 시점 방향**으로 이동하고 공격합니다. 다음 기술을 예약한 뒤에도 마우스·Q/E·터치 시점으로 발동 직전까지 방향을 고를 수 있습니다. 발동한 동작은 정해진 방향으로 마무리하며, 방향을 바꾸지 않으면 기존처럼 직선으로 이어집니다. 박힌 도끼는 원래 위치와 방향을 유지하고, 가로베기 때 새로 바라보는 방향으로 회수해 벱니다. 1번 돌진·2번 내려찍기의 방향 처리와 연계 조건은 그대로입니다.

돌진 피해는 8, 내려찍기 39, 가로베기 38입니다. 돌진 이동 속도를 18 → 27m/s로 높여 같은 돌진 시간 동안 이동 거리가 50% 증가했습니다(막힘 없는 평지에서 약 10m). 내려찍기 피해도 26 → 39로 50% 증가했습니다. 적에 부딪히거나 장애물을 만나면 돌진을 멈춥니다. 기술 대기시간은 각각 4초, 3.5초, 날아차기 1.2초, 가로베기 1.8초이며 무기 교체로 초기화되지 않습니다. 가로베기는 낮은 준비 자세, 큰 몸통 회전, 빠른 가로 휘두르기, 넓은 금빛 궤적과 강한 타격 정지·카메라 반동으로 기본 공격과 구분됩니다. 카메라 효과는 동작 줄이기 설정을 따릅니다. 마법사 직업은 아직 구현하지 않았습니다.

근접 자동 공격은 도끼 2.7m / 칼 2.6m에 대상 반지름을 더한 기존 사거리 안에서 가장 가까운 살아 있는 토끼·슬라임을 향합니다. 시야·높이 검사를 적용하며 도끼와 칼 모두 2초 간격으로 기본 공격합니다. 자동 공격과 좌클릭 직접 공격이 같은 간격을 공유하고 무기를 바꾸거나 스킬로 자동 베기를 취소해도 남은 기본 공격 대기 시간은 유지됩니다. 이 대기 시간은 스킬 사용을 막지 않으며, 카메라는 강제로 돌리지 않습니다. 자동 공격 중에도 이동할 수 있고, 전사 기술 입력은 자동 베기를 즉시 취소하고 먼저 실행됩니다. 기술 동작·박힌 도끼·예약 기술·진행 중인 연계 대기 시간에는 자동 공격하지 않습니다. 적이 사거리 밖으로 나가거나 쓰러지면 새 공격을 시작하지 않습니다. 일시정지·사망·활 장착 시에도 자동 공격하지 않습니다. 나무는 자동 공격을 시작하는 대상이 아니며, 좌클릭 또는 기술로 벌목합니다.

날아차기는 첫 적중 시 PRD(의사 난수 분포)로 약·중·강을 한 번 뽑습니다. 약은 18 피해 / 3m, 중은 26 피해 / 4.5m, 강은 36 피해 / 6m를 밀어냅니다. 한 번의 발차기에 맞는 여러 적에는 같은 단계가 적용됩니다. 강한 결과가 연속으로 나오지 않으면 다음 강한 결과의 확률이 높아지고, 강한 결과가 나오면 낮아집니다. 장기 목표 비율은 약 30%, 중 45%, 강 25%입니다. 첫 시도 확률과 장기 비율은 다릅니다. 빗나감·취소·R·무기 교체로 확률을 재추첨하거나 초기화하지 않습니다.

밀침은 실제 적의 좌표를 이동시키며, 강할수록 더 높이 떠서 몸이 기울어집니다. 벽과 바위, 들판 경계에서는 이동이 멈춰 실제 거리가 줄어듭니다. 가로베기는 최대 밀침 거리까지 연계할 수 있도록 전진 동작과 넓은 공격 범위를 갖습니다.

날아차기에 맞고 살아남은 적은 4초간 비틀거리며 머리 위에 금빛 표시가 생깁니다. 이 시간 안에 **그 적에게 다음으로 적중하는 공격 한 번은 치명타로 2배 피해**를 줍니다. 가로베기는 38 → 76, 기본 도끼 공격은 24 → 48이 되며 칼과 화살에도 적용됩니다. 날아차기 자체는 자신이 새로 만든 비틀거림의 혜택을 받지 않습니다. 빗나가거나 다른 적을 공격해도 해당 적의 기회는 유지되고, 적중 또는 4초 만료 시 사라집니다. 대상마다 따로 적용되며 처치·재등장·R로 초기화됩니다.

## 궁극기 · 회전베기

돌진 → 내려찍기 → 날아차기 → 가로베기를 각각 적에게 적중시키면 궁극기 1회를 보관합니다. 서로 다른 적에게 이어 맞혀도 인정하며, 발차기 강도와 피격 여부는 성공 조건에 영향을 주지 않습니다. 한 기술에서 여러 적을 맞혀도 연계 단계는 한 번만 올라갑니다. 가로베기 적중으로 준비가 된 뒤 5번을 미리 누르면 동작 종료 후 바로 회전베기로 이어집니다.

## 벌목과 목재

시작 위치 왼쪽의 작은 숲과 들판의 모든 소나무를 벨 수 있습니다. 도끼 기본 공격과 1~5 기술은 사냥과 같은 피해·범위·타이밍으로 적용됩니다. 나무도 연계 충전, 회전베기의 연속 적중·치명타·시간 연장에 인정됩니다. 날아차기는 나무를 밀지 않고 4초간 균열을 내며 다음 적중을 2배로 만듭니다. 나무와 목재 모두 벽 너머에서는 공격하거나 끌어모을 수 없습니다. 칼·화살은 나무 피해가 절반입니다.

작은 나무 체력 160 / 목재 4, 굵은 나무 체력 200 / 목재 6. 치명타로 베어내면 목재 2개 추가. 쓰러지는 나무는 즉시 통과할 수 있고, 떨어진 통나무는 3m 안에서 자동 수집됩니다. 2단계 회전베기는 6m 안의 목재를 끌어모읍니다. 나무는 60초 뒤 플레이어와 적이 비켜 있으면 다시 자랍니다. 수집하지 않은 목재는 이번 플레이 동안 남습니다.

T 또는 목재 패널의 버튼으로 손잡이를 강화합니다. 비용은 순서대로 목재 12 / 24 / 36개, 도끼의 벌목 피해만 +15% / +30% / +45%. 몬스터 피해와 칼·화살에는 적용되지 않습니다. 목재와 강화 단계는 사망·R·페이지 새로고침에도 유지됩니다.

빗나감, 실제 발동한 기술의 순서 변경, 이전 기술 종료 후 3초 안에 다음 기술을 시작하지 않음, 이동·점프로 도끼 회수, 무기 변경, 사망·R은 진행 중인 연계를 초기화합니다. 실패하면 돌진부터 다시 시작합니다. 쿨타임이나 조건 때문에 발동되지 않은 입력은 무시합니다. 이미 준비된 궁극기는 이동·피격·무기 교체·일시정지에도 유지되고, 사용 또는 사망·R로 소모됩니다. 충전은 1회까지만 보관합니다.

- 기본 2.5초, 0.25초마다 반경 3.2m 전방향 공격. 1단계 8 피해, 2단계 10 피해.
- 적이 맞은 회전 공격 3회가 연속되면 그 세 번째 공격이 2배 치명타가 되고 2단계로 강화됩니다. 이후에도 매 세 번째 연속 적중이 치명타입니다. 한 번에 여러 적을 맞혀도 1회로 세며, 빈 공격은 연속 횟수를 0으로 만듭니다. 2단계 자체는 끝까지 유지됩니다.
- 2단계는 반경 6m의 적을 초당 최대 6m 속도로 안쪽으로 끌어당깁니다. 적은 실제로 이동하며, 장애물·높이·시야 검사를 적용하고 플레이어 중심 1.1m 앞에서 멈춥니다. 공격과 흡입은 벽을 통과하지 않습니다.
- 치명타가 발생한 공격 주기 1회당 +0.25초, 처치한 적 1마리당 +0.5초. 전체 지속시간 상한 4초, 추가 시간 상한 1.5초. 한 주기에 여러 적이 치명타를 맞아도 치명타 시간 보너스는 한 번입니다.
- 기존 비틀거림도 다음 회전 타격을 치명타로 만들고 1회 소모됩니다. 연속 적중 치명타와 겹쳐도 피해는 2배까지만 적용합니다. 회전 중 별도의 무적은 없으며, 무기 교체나 사망·R로 중단되면 충전이 돌아오지 않습니다.
- 회전 중 이동 속도 3.4m/s. 카메라는 회전하지 않으며 1인칭에서도 몸 회전 때문에 시야가 강제로 돌아가지 않습니다.

HUD에 연계 단계·실패 사유·궁극기 준비·흡입 단계·남은 시간·추가 시간이 표시됩니다. 1단계는 금빛 회전 궤적, 2단계는 청록색 회전 궤적과 안으로 흐르는 바람으로 구분합니다.

## 사냥

토끼는 가까이 가면 도망치고, 슬라임은 접근하면 쫓아와 몸을 튕겨 공격합니다. 칼과 화살은 장애물 너머의 적을 맞힐 수 없습니다. 처치 시 피 대신 작은 입자가 퍼지며 사냥 횟수가 표시됩니다. 토끼는 약 13초, 슬라임은 약 17초 뒤 시작 위치에서 재등장하며, 플레이어가 그 위치에 너무 가까우면 재등장을 미룹니다. 6초 동안 맞지 않으면 체력이 천천히 회복됩니다. 사냥 기록은 현재 플레이 중에만 유지됩니다.

활은 당긴 정도에 따라 피해가 24에서 60까지, 화살 속도가 초당 19에서 44까지 증가합니다. 가득 당긴 상태를 계속 유지할 수 있으며 자동 발사되지 않습니다. 발사 후 다음 화살을 당기기까지 0.45초가 걸립니다.

## 수정할 곳

## 회피 · 쿨다운 기술 · 보존된 전투병 규칙

- 전투는 소수의 기술과 위치 선정으로 싸우는 액션 RPG를 바탕으로 합니다. 기존 1~5 기술·특성·2초 자동 공격은 유지합니다.
- F: 이동 방향으로 0.42초 동안 약 3.8m 회피. 무입력은 시선 방향. 첫 0.28초 무적, 4초 재사용. 벽을 통과하지 않고 현재 공격 동작을 취소하되 이미 적중한 연계 단계와 준비된 궁극기를 보존합니다. 회피 중 연계 시간은 멈추고 끝난 뒤 최소 2초를 줍니다. 회피로 도끼를 회수한 뒤에는 도끼를 든 날아차기 → 가로베기로 이어집니다. 타격 전 취소한 기술은 재시도할 수 있으며 피해나 연계 단계를 공짜로 얻지는 않습니다. 0.65초 미만 경직도 적중 단계를 보존하고, 그 이상의 큰 경직은 연계를 끊습니다. 마우스 좌클릭은 기존 공격/활 당기기·놓아 발사로 유지합니다.
- 6 전투 함성: 30초 재사용, 6초간 모든 무기 피해 +35%, 받는 피해 -25%. 기존 기술을 취소하지 않습니다. UI 버튼과 WebMCP도 같은 제한을 적용합니다.
- 아군·적군 방패병: 정면 피해 65% 감소, 돌진, 상황에 따른 함성. 측후면 공격으로 방어를 우회하고 플레이어 날아차기로 4초간 방패를 무너뜨립니다.
- 아군·적군 전사: 돌진, 내려찍기, 내려찍기 후 가로베기, 함성. 마지막 우두머리는 별도의 바닥 패턴 전투를 사용합니다.
- 아군·적군 궁수: 조준 사격, 가까운 적에게서 후방 회피. 발사 전 조준 방향이 고정되며 화살은 실제 이동하고 벽에 막힙니다. 치유 주민은 기존 지원 역할을 유지합니다.
- battle-rules.js의 범위·기본 피해·재사용·활 계산을 플레이어와 SoldierSkills가 공유합니다. NPC 기술 피해 계수는 아군 0.6 / 적 0.55, 조준 사격 0.4이며, 난도 보정은 별도입니다. NPC 돌진만 추가 0.65초 예고 후 출발합니다. AI는 거리에 맞는 기술과 체력/주변 적 수에 맞는 함성을 선택하고, 동시에 준비하는 적의 기술을 2개로 제한합니다.
- 붉은 범위는 적, 청록 범위는 아군입니다. 원=내려찍기, 부채꼴=가로베기, 넓은 띠=돌진, 얇은 선=사격. 경직과 날아차기로 준비 중 기술을 중단할 수 있고 재사용 시간은 반환하지 않습니다. 모든 부대 행동은 기존 경로 탐색을 사용합니다.
- 확인: node tests/raid-boss.mjs (파동·보상, 예고·안전 지대, 회피·차단, 증원, 면역, 바닥 시각화 일치, 실제 지형 배치·주민 회피·방치 전투), node tests/tactics.mjs (공통 전투 규칙), node tests/expansion.mjs (성장·건축·저장 회귀).

## 전투 흐름과 시점 복귀

- 회피 후 남은 연계는 무제한 보관하지 않습니다. 기본 3초(특성 최대 +1초), 회피 중 정지·회피 종료 후 최소 2초이며 F의 4초 재사용 때문에 회피만 반복해 무한 유지할 수 없습니다. 일반 이동으로 박힌 도끼를 회수하면 기존처럼 끊깁니다.
- 돌진 거리는 약 10m, 내려찍기 39 피해, 기본 자동 공격 2초 간격을 유지합니다. 적·아군 전투병과 보스의 예고 시간은 단축하지 않습니다.
- 야외 토벌 시작과 메뉴 닫기 버튼에서 마우스 시점을 다시 연결합니다. Esc는 마우스를 풀고 일시정지합니다. 브라우저가 마우스 잠금을 거절하면 우클릭 드래그·Q/E를 유지합니다. 토벌 정보는 마우스를 가로채지 않으며 주민 지시 버튼은 클릭할 수 있습니다.
- 확인: `node tests/combat-flow.mjs`, `node tests/camera-input.mjs`.
