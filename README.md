# 바람의 들판

게임 장르를 정하기 전, 이동 감각부터 만져 보는 싱글 플레이 3D 놀이터입니다.

## 실행

Node.js가 있는 환경에서 이 폴더를 열고 `node serve.mjs`를 실행한 뒤 http://127.0.0.1:4173 에 접속하세요. HTML 파일을 직접 더블 클릭하면 브라우저의 모듈 보안 제한 때문에 실행되지 않습니다.

## 조작

- WASD 또는 방향키: 카메라 방향을 기준으로 이동
- 마우스: 화면 클릭 후 자유 시점, 또는 누른 채 드래그
- Q / E: 키보드 시점 회전
- Shift: 달리기
- Space: 점프
- V: 1인칭 / 3인칭
- 마우스 휠: 카메라 거리, 가까이 당기면 1인칭
- R: 시작 위치
- Esc: 일시정지 / 마우스 해제
- 터치: 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 시점, 점프·달리기 버튼

## 수정할 곳

- `dist/movement.js`: 속도, 점프, 중력, 충돌. 렌더링과 독립된 120Hz 이동 시뮬레이션.
- `dist/environment.js`: 지형, 장애물, 캐릭터 모양, 조명.
- `dist/game.js`: 입력, 캐릭터 애니메이션, 1·3인칭 카메라.
- `dist/style.css`: 한국어 안내와 HUD.

Three.js 0.186.1을 `dist/vendor/`에 포함했습니다. Three.js는 MIT 라이선스이며 원문은 `dist/vendor/LICENSE`에 있습니다. UI 글꼴은 온라인일 때 Google Fonts의 Noto Sans KR을 쓰고, 오프라인에서는 시스템 글꼴로 대체됩니다. 로그인·멀티플레이·데이터 저장은 없는 프로토타입입니다. 캐릭터 충돌은 원기둥 형태를 간략화해 계산하며 바위 충돌 경계는 렌더링 형상과 약간 다를 수 있습니다.
